Key Notes

Textbook concepts from OpenStax Psychology 2e (paraphrased).

8.1 How Memory Functions §8.1, ≈pp. 248–253

  • Three operations: encoding, storage, retrieval (recall, recognition, relearning).
  • Atkinson–Shiffrin: sensory → short-term → long-term (with rehearsal). Baddeley–Hitch working memory as a richer STM model.
  • LTM: explicit (episodic/semantic) vs implicit (procedural, priming, emotional conditioning).

中文補充：先分清「編碼／儲存／提取」，再分「外顯 vs 內隱」。

8.2 Brain Areas §8.2, ≈pp. 254–257

  • Engram search (Lashley) → distributed memory; amygdala (emotional memory), hippocampus (new memory consolidation), cerebellum (procedural), prefrontal involvement in working memory themes.
  • Arousal / neurotransmitter & hormone effects; flashbulb memories feel vivid but are not perfectly accurate.

8.3 Problems with Memory §8.3, ≈pp. 258–267

  • Amnesia: anterograde vs retrograde; memory construction / reconstruction; suggestibility; eyewitness issues; misinformation effect (Loftus).
  • Forgetting: encoding failure, transience, absentmindedness, blocking; bias; persistence (unwanted memories). Interference: proactive vs retroactive.

8.4 Enhancing Memory §8.4, ≈pp. 268–278

  • Chunking, elaborative rehearsal, mnemonic devices, expressive writing themes, rehearsal spacing / practice testing ideas as presented in the chapter.

Further Theoretical Depth

External journals and classic books beyond the textbook sketch.

Atkinson and Shiffrin’s multistore model still organizes how textbooks teach sensory, short-term, and long-term memory.

Atkinson, R. C., & Shiffrin, R. M. (1968). Human memory: A proposed system and its control processes. In K. W. Spence & J. T. Spence (Eds.), The psychology of learning and motivation (Vol. 2, pp. 89–195). Academic Press. doi.org/10.1016/S0079-7421(08)60422-3

Baddeley and Hitch’s working-memory model replaces a single STM box with phonological and visuospatial subsystems plus a central executive.

Baddeley, A. D., & Hitch, G. (1974). Working memory. In G. H. Bower (Ed.), The psychology of learning and motivation (Vol. 8, pp. 47–89). Academic Press. doi.org/10.1016/S0079-7421(08)60452-1

Loftus and Palmer showed that wording can reshape eyewitness reports—foundational for the misinformation effect.

Loftus, E. F., & Palmer, J. C. (1974). Reconstruction of automobile destruction. Journal of Verbal Learning and Verbal Behavior, 13(5), 585–589. doi.org/10.1016/S0022-5371(74)80011-3

Ebbinghaus’s forgetting curve and savings on relearning remain the classic quantitative start of memory science.

Ebbinghaus, H. (1885/1913). Memory: A contribution to experimental psychology (H. A. Ruger & C. E. Bussenius, Trans.). Teachers College. archive.org

Must-know contrasts

High-yield comparisons for this chapter. Focus on common confusions and everyday examples. Paraphrased from OpenStax Psychology 2e ideas plus named classics; not verbatim textbook text.

Must-know contrast table

Encoding, storage, retrieval

ConceptCore ideaCommon confusionEveryday example
EncodingGetting information into memoryBlaming a “bad memory” when you never attended to the input (shallow/no encoding)At a loud party you smile, never repeat the name, and cannot recall it 30 seconds later
StorageMaintaining information over timeAssuming anything briefly heard is permanently filed in LTM without rehearsal or meaningYour childhood home address stays available for years after dense, repeated use
RetrievalAccessing stored information when neededTreating tip-of-the-tongue blanking as proof the memory was never storedYou know the actor’s name but blank during introductions—then it pops out in the lift later

Short-term/working vs long-term memory

ConceptCore ideaCommon confusionEveryday example
Short-term / working memoryLimited, active workspaceAssuming rehearsal always uploads to LTM, or that STM equals all of conscious thoughtYou rehearse a phone number long enough to dial it, then it vanishes
Long-term memoryVast, durable (with subtypes)Assuming LTM is a perfect video file that never reconstructs or distortsYou remember your childhood address, but the “memory” of a birthday party may blend years

Recall vs recognition

ConceptCore ideaCommon confusionEveryday example
RecallProduce the informationClaiming only free recall “counts” as real memory and recognition is cheatingA blank essay prompt forces you to produce the definition without options
RecognitionIdentify among optionsAssuming easy multiple-choice recognition proves deep mastery equal to recallYou pick the correct term from four options but cannot explain it from scratch later

Proactive vs retroactive interference

ConceptCore ideaCommon confusionEveryday example
Proactive interferenceOld learning disrupts newReversing proactive vs retroactive (forgetting which direction “pro/forward” points)Your old ATM PIN keeps popping up when you try to learn the new one
Retroactive interferenceNew learning disrupts oldReversing retroactive vs proactive (forgetting that “retro” means new hurts old)This semester’s locker combo crowds out last year’s when a friend asks for the old one

Theory vs evidence

Theory / claimSupporting evidenceLimits / challenges
Levels of processing: deeper (semantic) encoding yields better memory (Craik & Lockhart tradition)Semantic elaborations usually beat shallow rhyme/case judgments in lab tests“Depth” can be circular; transfer-appropriate processing also matters
Working memory is a multi-component system (Baddeley-style models)Phonological / visuospatial dissociations; dual-task interference patternsCapacity estimates and component boundaries still debated
Memory is reconstructive (schema / misinformation effects; Loftus tradition)Post-event information can alter reports; false memories demonstrable in labNot all memory is wildly inaccurate; emotion and repeated accurate rehearsal help; legal implications require care
